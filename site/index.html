Multi-agent · GraphRAG · Local-first · Python

A clinical question in - a cited, structured evidence summary out.

A team of specialized agents triages a biomedical question, retrieves evidence three ways - GraphRAG community reasoning, semantic vector search over a systematic-review corpus, and live web - then synthesizes a structured summary where every claim carries its source.

The pipeline

Specialized agents, one control loop

01

Triage the question

A triage agent checks the query for PICO completeness - population, intervention, comparator, outcome - and routes it: straight to research if it is specific enough, or to clarification if key dimensions are missing.

PICO routing · handoffs
02

Clarify and instruct

When needed, a clarifying agent asks 2-3 targeted questions; an instruction agent then rewrites everything into a detailed research brief - evidence hierarchy, structured-output sections, source priorities - before any retrieval runs.

clarifying · research brief
03

Retrieve evidence three ways

The research agent queries the local GraphRAG systematic-review corpus first, then supplements with semantic vector search and live web results - drawing on peer-reviewed literature, trial registries, and regulatory sources.

GraphRAG · vector ANN · web
04

Synthesize with citations

A summarizer assembles the findings into a structured report - executive summary, evidence review by study type, key data, clinical implications, limitations - with inline citations back to every source.

structured output · grounded
05

Record the run

Each run persists a durable record - query, output, and (as the team grows) task and progress-ledger snapshots - to a document store, so results and agent reasoning are inspectable after the fact.

Cosmos vCore · run records
Retrieval

Three modes over one corpus

Graph

GraphRAG communities

Microsoft GraphRAG indexes the corpus into entities, relationships, and hierarchical community summaries. search_sr_corpus runs global / local / drift / basic search for dataset-wide themes or paper-specific lookups.

Semantic

Vector ANN

Study chunks are embedded and retrieved by meaning - LanceDB today, moving to Postgres + pgvector with an HNSW index as the primary store. Nearest-neighbour recall for the passages that actually answer the question.

Web

Live evidence

A web-search tool expands beyond the corpus to current guidelines, registries, and labels - so the summary reflects both the curated review set and what has appeared since it was assembled.

Corpus

Grounded in a systematic-review set

Sources

Four databases, deduped

An ingest step unifies exports from PubMed, Scopus, Embase, and IEEE Xplore - parsing each format's quirks, deduping by DOI, and writing one clean document per study.

Index

Community summaries

GraphRAG buckets community reports by level into macro-root, intermediate, and leaf summaries - so the same corpus answers both "dominant themes" and "what does this one cluster say".

Local-first

Runs on your machine

The pipeline is designed to run locally with your own models - nothing about the corpus or a query has to leave the machine to get a grounded, cited answer.
